Important limitations

  • Network rules cover 200,000+ ad and tracker domains plus site-scoped paths. They cannot run full uBlock Origin scriptlets or procedural cosmetic filters.
  • Cosmetic selectors can occasionally hide a legitimate element. Turn cosmetic filtering off if a site misbehaves.
  • Filter lists are remote content when downloaded. Only use a source you trust.
  • Browser-internal pages, the Chrome Web Store, and other extensions cannot be modified.
  • A block rule can break site functionality. Use the per-site allowlist from the popup.
